# IT Automation & Enterprise Systems Support | Central Michigan University

In my IT Telecom Technician role at **Central Michigan University (CMU)**, I worked across enterprise IT support, identity and access administration, and systems migration. ## 1. Identity and Administrative Workflow Automation

### Operational context

Managing user identities and access rights in an enterprise environment involves repetitive administrative actions, consistent permission handling, and careful verification. Automation can support this work by reducing manual steps and making workflows easier to review.

### My involvement

- Used **PowerShell** and **Microsoft Graph** in connection with enterprise data and systems migration work.
- Worked with **Microsoft Entra ID** and **Active Directory** users and groups, as well as **SSO** and **MFA** support.
- Supported day-to-day administration across **Microsoft 365**, **Intune**, **Defender**, and **Purview**.
- Participated in troubleshooting, verification, and documentation of IT administrative workflows.

### Engineering considerations

Identity workflows require particular attention to least-privilege access, data validation, error handling, auditability, and human review for sensitive changes. Specific automation scripts, API calls, and results are not published here because their exact scope has not been documented for this public portfolio.

## 2. Physical Access-Control Migration: Lenel to Genetec

### Challenge

A campus-wide transition between access-control platforms requires careful translation of existing permissions into the destination system. Access groups, individual doors, and time-based rules must be configured and checked so the new system reflects approved access requirements.

### My involvement

- Helped review and map **existing access permissions** during the transition from **Lenel to Genetec**.
- Worked on assigning **doors to access groups** and configuring or recreating **time-based access rules** and access-control automations in Genetec.
- Supported verification and troubleshooting of assigned configurations, with manager guidance where appropriate.
- Documented work and coordinated on issues that required follow-up.

### What this demonstrated

- Adapting to a new enterprise platform during an active migration.
- Translating operational rules into system configurations.
- Applying careful review practices to security-sensitive changes.
- Working with technical colleagues to resolve configuration issues.

**Security note:** This summary intentionally omits campus building layouts, door identifiers, access schedules, credential data, permission mappings, and production configuration details.
